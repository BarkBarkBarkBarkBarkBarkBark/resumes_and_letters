## Selected Technical Projects

### Dark Horse Neuro / Neuralynx acquisition pipeline — 2026
\begin{itemize}
\item Built a Python orchestration layer to launch DHN-AQ headlessly over SSH, generate RC/CS session files, and coordinate Pegasus / NetCom replay workflows for human intracranial recordings.
\item Implemented an NRD replay bridge that re-broadcasts ATLAS-format UDP packets so archived Neuralynx sessions can be ingested by DHN-AQ as if hardware were live.
\item Automated compression-aware MED recording setup for 512-channel macro / micro configurations, including decimation, lossless/lossy options, and pre-flight network diagnostics.
\end{itemize}

### spike_discrim single-unit DSP workbench — 2026
\begin{itemize}
\item Benchmarked low-latency waveform representations for real-time single-unit discrimination using curated OSort snippets, synthetic data, AUC, balanced accuracy, mutual information, and KNN purity.
\item Built a Numba-accelerated WeightBank population code to score spike-likeness and project waveforms into afferent activation space for clustering and unit-separation analysis.
\end{itemize}

### SNN Agent real-time spike sorting — 2026
\begin{itemize}
\item Developed a streaming spiking neural network with bandpass filtering, Kalman noise gating, competitive STDP, and browser-based monitoring for live spike detection and sorting.
\item Evaluated 20 kHz real-time pipeline behavior across synthetic, .ncs, UDP, and LSL inputs with online decoding for closed-loop neurotech use cases.
\end{itemize}
