Neural Compression Validation

0.5 uV max difference across 20 million samples

Evaluate an existing DarkHorse Neuro conversion, not implement its compression algorithm.

Built
Evaluated DarkHorse Neuro compression on 20 million samples (one channel, 32 kHz; 625 s); maximum source-to-MED difference was 0.5 uV, with zero mismatches after rounding source values to whole microvolts.
Tested
Compared source CSC and reconstructed MED in physical units, then controlled for whole-microvolt rounding before identical offline sorting.
Result
Controlled MountainSort5 comparison of rounded inputs preserved all 35,587 spike frames for the compared unit (exact Jaccard 1.0).

Offline validation on a bounded single-channel slice; archived outputs reviewed, not a new raw-data rerun.

Spike Sorting and Neural Processing

38,145 snippets across 10 putative unit labels

Quantify waveform-feature behavior against reference unit assignments.

Built
Implemented waveform-feature evaluation across 38,145 spike snippets and 10 putative O-Sort unit labels; event-family KNN purity at k=5 was 95.04%.
Tested
Evaluated event-family WeightBank activations with nearest-neighbor purity and KMeans label matching on curated snippets.
Result
Measured 54.26% Hungarian-matched KMeans accuracy (ARI 0.3665) for that feature family; neighborhood purity is not sorter accuracy or biological ground truth.

Offline feature validation; streaming detection and competitive-learning sorting in SNNeuro remain prototypes.
