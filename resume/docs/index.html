Selected Engineering Projects

Neural Data Formats and Integrity

Make vendor recordings readable and check what changes during conversion.

Adapted a Neo-backed MED reader to skip corrupt parity channels whose metadata caused standard readers to abort, allowing processing without modifying source recordings. Developed validation and repair utilities for Neuralynx recordings with sample-count inconsistencies and missing recording-end metadata that prevented downstream conversion. Evaluated signal fidelity across 20 million samples on one channel (32 kHz; 625 s), comparing original CSC and compressed MED recordings. Measured a maximum amplitude difference of 0.5 µV, with exact agreement after whole-microvolt source rounding.

Python, NumPy, Neo, SpikeInterface, Neuralynx CSC, DarkHorse MED

Reader code

Neural Acquisition and Experimental Synchronization

Connect neural recordings to the experimental events needed to interpret them.

Built Python workflows for processing Intan recordings through SpikeInterface, including probe mapping, channel checks, spike sorting, waveform extraction, and quality metrics. Developed synchronization software to align PsychoPy behavioral events with RHX recordings, using matched event labels and affine clock fitting to characterize drift between recording systems.

Python, Intan RHD/RHX, PsychoPy, SpikeInterface, Kilosort4

Processing notebook

Waveform Analysis and Spike Sorting

Compare waveform representations for separating putative neural units.

Evaluated waveform representations across 38,145 spike snippets and 10 putative O-Sort unit labels, comparing how well different features preserved local waveform structure and supported clustering. Found that strong local neighbor consistency did not translate into equivalent global clustering agreement, distinguishing local waveform-feature consistency from whole-dataset clustering behavior.

Python, NumPy, scikit-learn, O-Sort

Technical report

Debugging Agent-Generated Software

Find and fix a slow CLI operation introduced during Codex-assisted development.

Investigated a performance regression in Hosaka, a command-line software platform, where agent-generated schema validation made listing seven records take approximately 70 seconds. Used execution timing logs to identify repeated validation as the bottleneck, then introduced content-based caching and regression tests to preserve checks for changed or invalid schemas.

Python, Codex, timing instrumentation, content-based caching, regression tests
